# my-ai-assistant

DIG now includes a local Agent Room and an iPhone SwiftUI client on the `dig/local-agent-chat` branch.

The iPhone baseline is intentionally not connected to Qubes/qrexec. It supports Face ID/device-passcode unlock, Security Researcher/Coder/System/QA selection, Owner Mode after local owner verification, and an HTTPS DIG server endpoint for chat.

See `ios/README.md` for iPhone build and readiness steps.
